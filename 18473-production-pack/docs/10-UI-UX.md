# UI / UX Direction

## Primary illusion
The experience should feel like handling a real contemporary smartphone, not navigating a game menu skinned as a phone.

## Visual principles
- grounded Mongolian contemporary UI language;
- fictional apps and brands;
- clean typography;
- restrained animation;
- realistic notification density;
- avoid neon/cyberpunk treatment.

## Main surfaces
### Lock screen
First interaction. `18473` should initially appear to be a possible code but not trivially solve every lock.

### Home screen
Apps unlock over time; some apps are present but initially inaccessible.

### Messages
Realistic thread list, dates, read states, voice notes, attachments, deleted/recovered markers only when justified.

### Gallery
Timeline-based browsing, metadata inspect, zoom, recently deleted/hidden albums.

### Browser
History, saved pages, searches. Search strings should sound like a real 25-year-old engineer, not exposition written for the player.

### Files
Encrypted archives, ordinary work files, startup folder, cabin folder.

### GRAPH
Starts as technical utility; later becomes an emotional threat. Confidence animation should be subtle until finale.

### Evidence board
Separate investigation workspace, not inside Tenuun's actual phone OS unless story justifies it. It can be Maral/player tool layer.

## Accessibility
- scalable text;
- transcripts for all audio;
- non-audio clue equivalents for required deductions;
- metadata and zoom targets keyboard-accessible on web;
- avoid color-only clue encoding.

## Spoiler discipline
Never show canonical names in debug-ish production UI. Internal IDs must not leak to player-visible labels.
