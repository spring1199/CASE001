# Phase 02 — Fake Phone OS

## Goal
Build the believable phone experience.

## Apps
Lock/home, Messages, Gallery, Calls, Mail, Browser, Notes, Files, Settings/System info. GRAPH is not presented as a consumer app until story unlock justifies it.

## Requirements
- mobile-first;
- realistic scrolling/history;
- deep links between artifacts;
- inspect metadata;
- audio playback + transcript;
- accessibility;
- no Case #001 logic hardcoded in components.

## Exit
Seed content can be browsed and discovery events reach engine state.
