# Phase 01 — Foundation

## Goal
Create a validated, testable, data-driven project skeleton.

## Deliverables
- install/configure Next.js 16.3.3 + React 19.2.x;
- strict TypeScript;
- lint;
- Vitest;
- Playwright smoke;
- Zod case schemas;
- pure trigger/deduction engine;
- Zustand player store;
- local persistence adapter;
- content loader for Case #001 seed.

## Do not
Do not build the full phone OS or author all narrative messages.

## Exit criteria
`npm run validate:pack` passes. All scripts pass and the home page loads the Case #001 manifest without exposing spoilers.
